# CMake Learning

---

Demos to learn how to use cmake.

## Intro

CMake_Learning1: small project in cmake.

CMake_Learning2: middle project in cmake.

## Notes

CMake_Learning2 needs GTest library. Please install it before using the project.

### Linux (Ubuntu/Debian)

```bash
sudo apt-get install libgtest-dev
```

### MacOS

```bash
brew install googletest
```
